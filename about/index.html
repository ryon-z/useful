일상의 번거로움을 덜어주는
생활 유틸리티 포털, GoModo

GoModo(고모도)는 별도의 회원가입, 앱 설치, 유료 결제 없이 웹 브라우저에서 즉시 실행되는 고품질 무료 생활 유틸리티 도구를 연구·개발하여 제공하는 공익형 웹 소프트웨어 스튜디오입니다. 복잡한 세법·노동법 산식과 금융 계산, 일상의 체감 경제 지표를 가장 직관적이고 정확하게 시각화합니다.

GoModo의 4대 핵심 원칙

1. 무서버 클라이언트 완결형 프라이버시

모든 연산은 사용자의 로컬 기기(브라우저) 내부에서 100% 자바스크립트로 수행됩니다. 입력하신 연봉, 자산, 생년월일, 금융 거래 내역은 중앙 서버로 일절 전송되지도, 데이터베이스에 저장되지도 않는 제로 데이터(Zero-Storage) 구조를 고수합니다.

2. 공공데이터 & 법령 기반의 무결성

대한민국 국세청, 고용노동부, 보건복지부, 한국천문연구원 및 미국 FRED·IRS, 일본 국세청 등 공식 국가 기관의 법령과 고시 요율을 매일 대조 검증합니다. 자체 자동화 품질 게이트(Zero-Defect Audit) 파이프라인을 통과한 신뢰도 높은 알고리즘만 배포합니다.

3. 전 연령 친화적 고대비 반응형 UI

작은 스마트폰 화면이나 카카오톡 인앱 웹뷰에서도 입력폼이 찌그러지거나 잘리지 않도록 100dvh Safe-Area 대응과 글자 크기, 터치 영역, 명도 대비를 세심하게 다듬었습니다. 별도의 계산하기 버튼 없이 입력 즉시 실시간(Instant Reactivity)으로 결과를 표시합니다.

4. 상태 보존형 바이럴 공유 (State Preservation)

입력된 조건과 결과가 브라우저 URL 쿼리 파라미터로 실시간 동기화됩니다. 계산 결과를 카카오톡, 라인, X(트위터) 등으로 공유하면 상대방도 동일한 계산 결과 화면을 1초 만에 그대로 복원하여 열람할 수 있습니다.
